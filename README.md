# busybar-rust

Rust HTTP client and CLI for [busybar](https://busy.app/). The BUSY Bar spec can be found [here](https://api.busy.app/busybar/docs?urls.primaryName=1.1.1).

For the Rust docs, see [docs.rs](https://docs.rs/busylib). Add to your crate by running `cargo add busylib` or adding
`busylib` to your dependencies, e.g.

```toml
[dependencies]
busylib = "0.0.10" # check latest version https://crates.io/crates/busylib
```

To install the CLI, run `cargo install busybar --locked` (and run `busybar help` to see the available commands).
