# API client

Add to your crate by running `cargo add busylib` or adding `busylib` to your dependencies, e.g.

```toml
[dependencies]
busylib = "0.0.10" # check latest version https://crates.io/crates/busylib
```

For the Rust docs, see [docs.rs](https://docs.rs/busylib).

## Example apps

If you want more inspiration on how to use `busylib`, than the small examples which can be found in the book,
 you can look at the source code of these apps:
